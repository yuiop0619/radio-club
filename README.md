# RADIO CLUB

致敬今敏导演《红辣椒》中网络酒吧的同人站点。写下委托，抽塔罗牌，与七位预设角色对话，完成词联想和句子完成测试，生成一份用于娱乐与自我梳理的报告。

这是原生 HTML/CSS/JavaScript 静态网站。分析使用本地关键词、规则和预设文本，不调用大模型；分数不是心理量表，也不构成医疗或心理诊断。角色的叙事台词不会测量真实的删改、停顿或心理状态。

## 运行

推荐 Node.js 20+（运行静态服务不需要安装依赖）：

```sh
node tools/server.cjs
# http://127.0.0.1:8080
```

也可 `python -m http.server 8080`。直接打开 `index.html` 可用于本地体验；localStorage 不可用时尝试 window.name 兜底，不保证所有浏览器的 file:// 跨页行为。分享必须从托管网站生成，不能把本机文件路径发给别人。

Windows：`./tools/server.ps1 -Port 8080`。静态站部署只需根目录 HTML、favicon.ico 和 assets/，不需要上传测试、工具或 cloudfunctions。云函数有独立部署流程。

## 功能与数据

- 委托：昵称、正文与可选资料。编辑保留当前测试；“新建委托”生成新档案并清空当前测试，最近五份历史保存在本机，可在委托页恢复。
- 塔罗：五张解读、三张时间线和每日一牌；翻牌进度可恢复，切换语言不重抽。
- 精神分析：七位预设大师解梦、12 次词联想、6 道句子完成题。切换语言不清空输入，已保存的答案可恢复。
- 鉴定书：依据统一档案生成，包含 SCT、正确牌阵位置和关键词证据；无需等台词播放完即可阅读，支持打印。
- 树洞：默认仅本机保存。自动回声明确标为预设内容，不冒充真人。公开树洞需要配置安全云函数，再由访客主动连接、选择公开投递。
- 中日切换、可跳过的打字效果、减少动态效果设置、键盘按钮与表单标签。

## 隐私和分享

委托和测试默认保存在浏览器中，没有主动上传接口。浏览器清理站点数据会删除本机档案；写入失败会显示提示，不显示保存成功。

报告默认分享不含姓名、生日和原文的摘要；勾选完整档案后才包含原始资料。先查看预览，再复制链接。新链接用 `#c=` / `#n=` 片段承载数据，片段不随 HTTP 页面请求发送给服务器，但对页面脚本和链接持有人可见；Base64 不是加密。已分发的链接副本不能撤回。旧 `?c=` / `?n=` 链接停止解析并提示重新生成：浏览器首次请求已经可能发送旧查询数据，页面无法撤回该请求。

连接公开树洞会加载 CloudBase SDK 并建立匿名身份。选择公开投递后，纸条正文、署名、心情和真人回复会上传并对其他访客可见；委托档案不会随纸条上传。公开纸条通过作者身份校验撤回，举报会得到真实受理编号。匿名身份丢失后不能恢复作者权限，不能把本机“mine”标志当成授权。

当前配置保持公开服务关闭，直到完成 [云端部署](docs/cloud-deployment.md)。旧版公开数据库必须由管理员迁移或关闭客户端直写权限；前端升级不会清理历史云端资料，也无法替换云端权限配置。

## 开发与检查

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
npm run images
```

依赖仅用于开发：Node 内置测试覆盖模型、存储及云端操作；Playwright 覆盖真实页面和模拟云端两用户交互，拦截所有外网请求，不向生产留言板写测试数据。`npm run images` 从保留的原图生成 WebP 与会诊头像 PNG 回退。CI 在推送与 PR 时执行逻辑与浏览器回归。

## 目录

```text
*.html                 静态页面
assets/js/model.js     档案版本、结构校验和字段边界
assets/js/store.js     本机存储、档案与历史
assets/js/share.js     片段链接、解析和复制
assets/js/engine.js    规则分析与报告模型
assets/js/*-page.js    页面控制器
assets/js/treehole*    本地纸条、公开操作与重试队列
assets/js/cloud-config.js  公开服务配置（默认关闭）
assets/img/            原始素材及响应式衍生资源
cloudfunctions/treehole/  带鉴权、事务与幂等控制的云函数
tests/                 逻辑、浏览器回归及模拟数据库
tools/                 本地预览与素材处理
```

修复依据、验证边界和资源指标见 [修复记录](docs/fixes.md)。
