# RADIO CLUB

> 一间只存在于网络上的酒吧。你带着想不明白的事来，梦侦探萨弗兰用塔罗与精神分析，替你把线头理清楚。

致敬今敏导演动画电影《红辣椒》（パプリカ / Paprika, 2006）中虚构网站 **RADIO CLUB** 的同人复刻站点。
片中红辣椒递给侦探粉川一张印着网址的名片，他登录后走进这间网络酒吧——本作把那张名片背后的世界做成了真实可交互的网站。

---

## 一句话介绍

**一个完全离线、零依赖、零上传的「生成式心理鉴定」网站**：你写下委托 → 抽五张塔罗 → 做罗夏墨迹与词联想 → 系统本地推理出一份专属鉴定书，并可生成链接分享出去。

---

## 核心亮点

| 亮点 | 说明 |
|---|---|
| 完整交互链路 | 点单 → 塔罗 → 墨迹 → 联想 → 鉴定书，五步全部真实可跑通，不是静态展示页 |
| 本地生成式推理 | 情感谱、罗夏归类、荣格式「复合」检测、数秘与假说评分，全部在浏览器内计算，无 API |
| 隐私优先 | 委托内容只存 localStorage，不上传任何服务器；分享链接把数据编码在 URL 里，同样是点对点 |
| 中／日双语 | 默认中文，页脚一键切回日文版致敬原作，选择会被记住 |
| 四个电影彩蛋 | 17 层电梯故障、梦境大游行、镜中人与洞、红辣椒的名片 |
| 复古完成度 | 2006 年假浏览器外壳、CRT 噪点与扫描线、SVG 侦探头像（视线追踪＋眨眼＋说话嘴型） |
| 可访问性 | 移动端适配、`prefers-reduced-motion` 支持、键盘可操作的交互元素 |

## 本地运行

无需构建、无需安装依赖，任选一种：

```bash
# 方式一：直接双击 index.html（file:// 亦可运行，数据会降级存到 window.name）

# 方式二：起个静态服务器（推荐，localStorage 行为最完整）
python -m http.server 8080
# 然后打开 http://localhost:8080
```

部署：把整个目录丢到 GitHub Pages / Vercel / Cloudflare Pages 即可，纯静态。

## 推理引擎是怎么工作的

1. **情感谱**：对委托正文、梦境、反复想起的话、墨迹与联想回答做关键词统计，输出八维情绪强度，并标出「你一次都没提到的那种情绪」。
2. **罗夏归类**：把五张墨迹的回答映射到面具／昆虫／解剖／人物／动物／植物／机械／建筑／回避，给出主导类别的解读。
3. **词联想复合检测**：记录每个刺激词的反应潜伏期，识别拒答、重复、强复合（>5s）、复合（>2.5s）、过速（<0.9s）。
4. **数秘**：生日推算生命数、星座与本命塔罗牌。
5. **假说生成**：按加权评分从六个心理学假说中选出最贴合的两条，并给出可执行处方与「我还想知道」的追问。

所有内容均在本地生成，无网络请求。

## 电影彩蛋

- **17 层电梯** — 首页电梯升到 17F 后，整层数字都变成 17，全站轻微故障一下（致敬片中粉川对 17 层的恐惧）。
- **梦境大游行** — 首页横滚的游行队伍：家电、玩偶、人偶、自由女神，全都往同一个方向去。
- **镜中人与洞** — 首页「今日的镜子」，点一下洞口，镜子里的人会浮现。
- **红辣椒的名片** — 首次来访时，右下角会递上一张名片，写有本站网址。

## 隐私与免责

- 全站离线运行，委托内容、抽牌结果、测试反应只保存在你自己的浏览器里，**不会上传到任何地方**。
- 分享链接把档案 Base64 编码在 URL 中，链接本身即数据，不经过服务器。请注意：**拿到链接的人能看到你写的内容**，敏感内容请勿分享。
- 塔罗与精神分析内容仅供娱乐与自我梳理，**不构成医疗或心理诊断**。若你正经历真实困扰，请寻求专业帮助——萨弗兰也会这么建议。
