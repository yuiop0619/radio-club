# 黑客松获奖评估与提升方案（赛道二 · 抽象向）

> 评估日期：2026-09-10
> 评估对象：RADIO CLUB（`G:\radio-club\repository`，13 页，Vue 3 + TS + Pinia + Vite + Node）

---

## 0. 一句话结论

**现状拿奖概率不高，根因只有一个：这不是一个 AI 作品。**
全套"解梦 / 鉴定 / 塔罗解读"是本地关键词规则 + 预设文本，README 自己写着"不调用大模型"。评委只要问一句"AI 在哪"，就会崩。

**但底子极好**——世界观、完成度、工程化、隐私设计都在水准之上。
所以最优解不是推倒重来，而是**给它一个只有 AI 才能实现的灵魂**。

## 1. 获奖概率评估

> 概率为"进入获奖名次（三等及以上）"的主观判断，基于我目前掌握的有限信息。**如果告诉我赛事名称与评分维度，我可以重新校准。**

### 1.2 为什么现状偏低——三个致命扣分

| 扣分项 | 说明 |
|---|---|
| **没有 AI** | AI 赛道最大硬伤。规则引擎 + 预设文本，任何"智能"都能被评委拆穿 |
| **同人复刻** | 是《红辣椒》的复刻站点。"致敬"在评审眼里常常等于"没有原创作品" |
| **没有"人"** | 没有真实用户、没有真实数据、没有社会议题。评审看不到"影响" |

### 1.3 已有的强加分项（不要拆掉）

- **世界观完整**：2006 时间胶囊、七位大师、树洞、17 层电梯故障的 404 页
- **工程化扎实**：Vue 3 + TS + Pinia + Vite，多页应用，有 core/application/cloud/counter + Playwright 浏览器测试
- **隐私设计是差异化亮点**：本机优先、分享链接用 `#c=` 片段不随 HTTP 发送、默认不含原文——这在 AI 赛道里是稀缺叙事
- **完成度高**：双语、无障碍、移动端、分享图、成就系统、环境音

## 2. 三条路线

### 路线 A：AI 化改造（保底，改动最小）

把现有的规则引擎**保留为骨架**，在其上叠加一层 LLM 作为"叙事层"。不是套壳聊天，而是让模型把用户输入与规则结果**编织成一段有文学性的回应**。

| 接入点 | 现在 | 改造后 |
|---|---|---|
| 委托回信 | 预设模板 | LLM 读你的正文，写一封"萨弗兰的回信" |
| 精神分析 | 关键词命中 → 固定解读 | LLM 把 12 词联想 + 6 题 SCT **编织成一段叙事性解读** |
| 塔罗 | 牌义库拼接 | LLM 结合牌阵与你的问题生成解读 |
| 树洞回声 | 明确标注为预设 | LLM 生成"回声"，但仍标注为 AI |
| 鉴定书 | 规则排版 | LLM 生成"结论段"，保留证据链 |

- **优点**：复用全部已有资产，1–2 天可完成
- **缺点**：容易被归为"给现有产品加了个 API"
- **风险**：必须守住"不构成心理诊断"的免责声明

### 路线 B：抽象化重述（不写代码，改叙事与呈现）

不新增功能，改造**表达方式**：
- 把定位从"致敬站点"改成"**以今敏为方法的原创数字剧场**"
- 首页开场加一段"这不是还原，是另一场梦"的宣言
- 强调"AI 不是助手，而是这家酒吧的常客"——即使现在没有 AI，先把叙事的坑挖好

- **优点**：零成本，见效快
- **缺点**：叙事骗不过"AI 在哪"这一问，必须与 A 或 C 组合

### 路线 C：17F 新概念（推荐 ★）

在 RADIO CLUB 同一栋楼里，长出一个**只有 AI 才做得出来**的抽象作品。详见下一节。

## 3. 推荐概念：《17F · 失物认领处》

**英文名**：ROOM 17 / LOST & FOUND
**一句话 pitch**：一家只存在于梦里的酒吧，电梯第 17 层存放着所有人弄丢的记忆——AI 会从里面挑一段**不属于你的记忆**，让你认领。

### 3.1 母题

> 当 AI 能生成"你没有过的记忆"，你还是你吗？

### 3.2 为什么必须是 AI（这是答评委的核武器）

| | 规则引擎能做到 | 只有 LLM 能做到 |
|---|---|---|
| 记忆来源 | 从预设池里抽一条 | 根据你**此刻的一句话**，即时生成一段从未存在、却读起来像你自己的记忆 |
| 匹配逻辑 | 关键词命中 | 语义层面的"这段记忆像不像你" |

**这是本质区别，也是这个作品存在的理由。**

### 3.3 与现有项目的关系

- **同一栋楼**：RADIO CLUB 是 1F 的酒吧，17F 是楼上那个不存在的楼层
- **现成素材**：`404.html` 已经是电梯故障主题（23F → ??F → --F），直接继承
- **可复用**：全部视觉资产、Vue 工程、Node 后端、云函数、分享图、环境音
- **独立成篇**：`room.html` + `wall.html` 两页即可，不破坏现有 13 页

### 3.4 核心循环（60 秒 wow）

1. **电梯（开场）**：你输入一个词或一句话（提示："今天丢在楼下的一句话"）
2. **上行**：电梯灯牌跳动，23 … 17？（氛围动画 + 环境音）
3. **门开**：AI 生成一间房 + 一段**第一人称记忆**（3–5 句），记忆里有一件"你弄丢的东西"
4. **认领 / 放回**：
   - 认领 → 存入个人档案，可回看
   - 放回 → 进入**公共墙**，被下一个访客读到
5. **公共墙**：所有访客放回的记忆碎片汇成一面墙（匿名、脱敏），可随机读到"别人弄丢的东西"
6. **离开**：房间消失，电梯关门

**情绪高潮**：门打开的那一下——一段你不记得、但读起来像你的记忆。

### 3.5 抽象层（评委爱听的话术）

| 意象 | 所指 |
|---|---|
| 电梯 | 意识的层级 |
| 17F | 潜意识的夹层，一个"不存在"的楼层 |
| 失物 | 被遗忘、被压抑的记忆 |
| AI | 不是助手，是**保管员**——它保管着从未属于任何人的记忆 |
| 放回公共墙 | 集体潜意识；你的私密记忆成为他人的素材 |

### 3.6 90 秒 Demo 脚本

| 时间 | 画面 |
|---|---|
| 0–10s | 黑屏，电梯"叮"。字幕：**"这栋楼没有 17 层。"** |
| 10–25s | 输入一句话 → 电梯上行 → 灯牌 23 … 17 |
| 25–45s | 门开，房间浮现，AI 生成的记忆**逐字浮现** |
| 45–60s | 选择「认领」或「放回」→ 公共墙上出现别人的碎片 |
| 60–80s | 快闪：不同人输入不同的词，生成不同的房间（展示**生成力**） |
| 80–90s | 黑屏字幕：**"你不是在找回记忆。你是在制造它。"** |

### 3.7 落地拆解

| 模块 | 内容 | 估时 |
|---|---|---|
| 电梯与房间 | `room.html` + `room.js`，复用现有视觉与打字机效果 | 1 天 |
| 公共墙 | `wall.html` + `/api/wall`（存取放回的记忆） | 0.5 天 |
| 生成接口 | `/api/room`：prompt 工程 + few-shot + 兜底模板 | 0.5 天 |
| 氛围打磨 | 环境音联动、转场、移动端 | 1 天 |
| Demo 录制 | 90 秒脚本 + 字幕 | 0.5 天 |

**模型选型**：
- 云 API（通义千问 / DeepSeek）：接入快，但需要密钥与网络
- 本地模型（Qwen + OpenVINO）：离线可跑，符合"本地 AI"叙事，演示更稳（不依赖现场网络）

### 3.8 风险与对策

| 风险 | 对策 |
|---|---|
| 生成质量不稳定 | 强 prompt + few-shot 示例 + 失败时回退到预设模板，保证"永不空白" |
| 内容安全 | 输入前置过滤 + 输出后置敏感词检查 |
| 密钥泄露 | 全部走后端代理，密钥不落前端；本地模型则无此问题 |
| 演示现场断网 | 优先本地模型；云 API 时预生成一批 fallback |

## 4. 无论走哪条路，都建议先做的三件事

1. **接入一个真实模型**——这是 AI 赛道的入场券，路线 A 或 C 都绕不开
2. **改叙事口径**——从"复刻"改成"致敬 + 再创作"，明确署名与免责
3. **录一支 90 秒 Demo**——评审看片的时间远多于看代码
