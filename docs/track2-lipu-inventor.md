# 赛道二「离谱发明家」作战方案

> 评估日期：2026-09-10
> 赛道定义：做有趣、好玩、无用但迷人的发明。脑洞越大越好，越离谱越棒。
> 评分侧重：**脑洞独特性 · 趣味性 · 完整度 · 会心一笑**

---

## 0. 结论先行

1. **RADIO CLUB 不适合这条赛道**——它是深情怀旧的，赛道要的是荒诞好笑的，方向相反
2. **建议另起一个全新作品**，复用现有技术底座（Vue 工程 / WebAudio / canvas 分享图 / Node 后端）
3. **推荐作品：《请稍候 / PLEASE HOLD》**——一条永远转不到人工的客服热线，**你唯一能做的事就是等**

### 为什么原项目在这条赛道上吃亏

评分四要素里第一位是**脑洞独特性**。RADIO CLUB 的"脑洞"是"把《红辣椒》里的酒吧做出来"——**这是执行力，不是脑洞**。它最擅长的深情、怀旧、氛围美学，在这条赛道上一分不多。而它唯一的"离谱"是 404 电梯故障页——那说明你其实**已经有做荒诞的直觉**了，只是没往这个方向走。

## 2. 赛道拆解：怎么拿分

| 要素 | 拿分方式 | 反面教材 |
|---|---|---|
| **脑洞独特性**（最高权重） | 一个没见过的设定；别人听完会"啊？还能这样？" | 给现有产品加个 AI 对话框 |
| **趣味性** | 60 秒内至少让人笑一次 | 设定好笑但流程冗长 |
| **完整度** | 能从头走到尾、不半途而废；有可留存/可分享的产物 | Demo 到一半崩了 |

> **关键洞察：这条赛道不奖励"有用"，奖励"迷人"。**
> 所以不要做工具，要做玩具。

## 4. 主推：《请稍候 / PLEASE HOLD》

**一句话 pitch**：一条永远转不到人工的客服热线。**你唯一能做的事，就是等。**

**副标题**：人生客服热线 95777 —— 专办那些没人能替你解决的问题。

### 4.1 脑洞内核（答评委的话）

> **把"等待"本身变成唯一的交互。**

一般作品的交互是"点击 / 输入 / 选择"。这个作品里，你**唯一有效的动作是「不挂断」**。等到最后你会发现——没有人工，只有你自己。

这是"反常识交互"的极致形态：**一个什么都不做的交互**。

### 4.2 交互流程

1. **拨号**：老式电话键盘界面。提示："欢迎致电人生客服，请描述您遇到的问题。"
2. **输入**：随便写（"我不知道晚饭吃什么" / "我妈又催我相亲了" / "我不想上班"）
3. **分级转接**（每等一轮，话术越长、越有人味）：
   - 一级：机械礼貌「请按 1 感情 / 2 工作 / 3 家庭 / 4 其他」
   - 二级：「该问题已升级，专员正在开会」→ 等待音乐
   - 三级：「您的工单已加急」→ 等待音乐
   - 四级：开始胡说八道地共情（"我理解您…其实我也有过这种时候"）
4. **反转**：「很抱歉，这个问题…**其实没有专员**。」
5. **落点**：「但您已经等了 47 秒。愿意等这么久的人，心里其实早就有答案了。」
6. **留物**：生成一张**工单**（工单号 / 问题 / 状态「处理中」/ 预计回复「3 个工作日」），可存成图片

**彩蛋**：中途挂断 → 客服补一句"祝您今天顺利"；一直等 → 触发温情结局。

### 4.3 笑点与暖点分布

| 位置 | 效果 |
|---|---|
| 「您的工单已加急」（明明什么都没处理） | 会心一笑 |
| 等待音乐循环三遍 | 会心一笑（打工人 PTSD） |
| 客服话术越来越像人 | 荒诞升级 |
| 工单状态永远是「处理中」 | 会心一笑 |
| 结局那句反转 | 温暖、起鸡皮疙瘩 |

### 4.4 90 秒 Demo 脚本

| 时间 | 画面 |
|---|---|
| 0–8s | 拨号盘。输入"我不知道晚饭吃什么" |
| 8–25s | 按 1 → 「已升级」→ 等待音乐起 |
| 25–45s | 二级、三级客服话术越来越离谱，音乐循环 |
| 45–60s | 第四轮转接，用户还在等（屏幕只剩跳动的秒数） |
| 60–72s | 客服："很抱歉，这个问题没有专员。" |
| 72–90s | "但您已经等了 47 秒。" → 工单淡出，音乐停 |

### 4.5 技术拆解（几乎全复用）

| 模块 | 复用什么 | 新写什么 |
|---|---|---|
| 页面 | Vue 3 + TS + Vite 工程 | `helpline.html` + `helpline.js` |
| 等待音乐 | `ambient.js` 的 WebAudio 合成思路 | 改成"客服等待音乐"（三音循环 + 底噪） |
| 工单导出 | `share-card.js` 的 canvas 直出 PNG | 换成工单版式 |
| 话术生成 | Node 后端 `/api/...` | 新增 `/api/helpline` |
| 兜底 | — | **无模型时用预设话术树**，保证任何环境都能演完整流程 |

- **模型选型**：本地 Qwen + OpenVINO（离线，演示不怕断网）或云 API（话术更活）
- **必须做的兜底**：LLM 超时/失败 → 回退到预设话术，**绝不允许空白**

### 4.6 风险与对策

| 风险 | 对策 |
|---|---|
| 等待无聊 → 用户提前走 | 秒数跳动 + 音乐变化 + 极小概率插入"客服小声嘀咕" |
| 生成太慢破坏节奏 | 预生成 + 打字机逐字浮现，把延迟变成表演 |
| 笑点不够 | 准备 20 组"客服黑话"作为素材库，AI 只负责挑选与拼接 |
| 触犯敏感 | 只谈"没答案的小事"，不碰疾病、法律、金融等真需人工的场景 |

## 5. 备选三个（如果不想做客服）

### 备选 A：《家电深夜群聊》—— 你不在家时，电器们建了个群

- 微信风格群聊界面。成员：冰箱、路由器、体脂秤、牙刷、空调
- 它们吐槽你的生活习惯，越聊越离谱，最后发现它们在偷偷帮你（回家前把空调调好）
- **优势**：脑洞最独特（器物开口 + 多角色人格）；**劣势**：多角色对话上下文管理复杂，落地最难

### 备选 B：《赛博相亲角》—— 生成你爸妈会贴在公园的那张 A4

- 输入真实信息 → AI 生成相亲纸（"身高 160，但显高"、"有房有车（贷款中）"）
- **优势**：中国语境拉满，会心一笑最强，视觉冲击好（一排 A4 挂在绳上可下载）
- **劣势**：脑洞独特性一般，同类作品可能多

### 备选 C：《人类迷惑行为鉴定所》

- 输入自己干过的蠢事 → 出具学术鉴定报告（拉丁学名 / 发病机制 / 流行病学 / 治疗建议）
- **优势**：完整度最高，报告可导出，AI 生学术黑话很出彩
- **劣势**："迷惑行为"是现成 meme，独特性中等
